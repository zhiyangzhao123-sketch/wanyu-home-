所里没有自己的云盘。文件靠 U 盘传，或者谁在群里发一下。

我自己那台 MacBook 上有几个人的资料：扫描件、身份信息、几张手写便条的照片。放在电脑里，我还能说服自己“这是我的电脑”。可一旦丢进网盘同步，我就不确定了。那到底是我的私人文件夹，还是别人服务器上的数据。

今天试了 Cryptomator。它做的事很直白：**文件在你自己的电脑上先加密，加密之后才上传。**

装上之后我建了一个“保险库”，指定到网盘里的一个文件夹，设了个密码。之后它看起来跟普通文件夹一样，能拖能存。不看的时候，它只是一堆打不开的乱码文件。

## 这个工具是什么

Cryptomator，GitHub 上的开源项目，一万六千多颗星。给云盘里的文件做**客户端加密**——加密在本机完成，上传的已经是密文。

它叫“零知识”。服务商拿到的只有加密后的东西。没有密码，也就没有办法解开。

## 怎么用

1. 官网下载桌面版（Windows / macOS / Linux），Mac 上也可以 `brew install --cask cryptomator`。
2. 新建保险库（vault），选一个位置——通常是网盘同步的那个文件夹。
3. 设一个密码。**这个密码没有找回途径**，忘了就真的打不开了。
4. 平时用就“解锁”，文件夹出现，正常拖放；用完“锁定”，它变回乱码。

## 什么时候能用，什么时候不能

**能用**：必须用网盘同步、文件本身又敏感的时候。当事人的资料、还没公开的合同、病历。

**不能用的地方，得说清楚**：

- **它加密的是“存着”这一步，不是“用着”这一步。** 解锁期间文件是明文，系统的临时文件、预览缩略图、剪贴板都可能留下痕迹。
- **密码丢了没人救得了。** 零知识的另一面就是这个：厂商也没有钥匙。
- **手机端要另外买。** 桌面版个人使用免费。iOS 和 Android 的完整功能各是 €29.99，一次买断，按平台分别算。
- **连桌面端的深色模式也要钱**，从 €29.99 起。
- **公司电脑装不了。** 那台 Windows 什么都不能装，这条路只在个人设备上走得通。

## 今天学到的

- 加密不是在网盘上加一个开关。是在自己的电脑上先换一次手。
- “零知识”听着安全，代价是钥匙只有你有。丢了就是丢了。
- 免费软件常常把手机端单卖；看价格要看整条链路，不是看首页那个 Free。
- 真正需要保护的往往不是文件本身，是“它被谁看到”这件事。
