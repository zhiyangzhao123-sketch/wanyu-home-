我的书签栏早就不够用了。七月底刚进所里的时候只有十几个，现在几百个，挤成一条缝，标题只剩前两个字。

三种东西混在一起：法条页面、判例、还有几个所里的内网地址。内网的打不开的时候，我还得先猜是网断了还是链接过期。

这周三我花了两个小时整理。先按月份删，再按重复删，删到最后还是乱。问题不在数量，在于我一直用“收藏”当“记住”。

昨天晚上试了一个叫 Linkit 的书签管理器。它是桌面软件，数据存在自己电脑上，不联网也能开。装的时候只用了一行命令。

我把浏览器里的书签导成 HTML，整份拖进去。它自动分了类，还标出十几个打不开的链接——有四条是我早就该删的旧地址。

到十一点，书签栏剩下两百多个。第一次能一眼看完。

## 它是什么

[Linkit](https://github.com/blue-idea/linkit) 是一个本地优先的桌面书签管理器。372 星，MIT 协议。Go + Wails + React 写的，macOS、Windows、Linux 都有安装包。

书签存在本机的 SQLite 里，不用注册账号。带重复检测和死链检测。有分类树和收藏集。也能从 Chrome、Firefox、Safari、Edge 的书签直接导入。

## 怎么用

Mac 上用 Homebrew 装：

```bash
brew install blue-idea/tap/linkit
```

不想用命令行的话，去 [Releases](https://github.com/blue-idea/linkit/releases) 下 DMG，或者 Windows 的 exe。

装完先从浏览器导出书签。Chrome 是「书签管理器 → 整理 → 导出书签」，得到一个 HTML 文件。然后在这个软件里选导入，把文件拖进去就行。

## 什么时候能用，什么时候别用

**能用**：书签太多、想按主题分组、想找出打不开的旧链接。这部分不联网也照常跑。

**AI 摘要和语义搜索要自备模型。** 它不附带 key，要么填一个 DeepSeek 之类的接口地址，要么在本机跑 Ollama。这一步我没弄成，所以那部分我一句也没法替它吹。

**云端同步会把链接传到 Supabase。** 服务是它自己的，数据隔离做得还行，但**所里的内网地址我是不会同步的**——那不是我一个人的东西。

**本地库没有云端备份。** SQLite 文件坏了就是坏了，得自己拷一份出来。

还有一个安装上的坑。这个软件目前没做苹果公证，直接下 DMG 可能被拦。用 Homebrew 装的话，安装脚本会顺手把隔离标记清掉。

## 今天学到的

- 书签乱，不是存得太多，是没有分类的入口。工具能帮你分，但分法得自己想。
- 有死链检测确实省事。过期链接不删，翻的时候就一直踩。
- 「本地优先」四个字值得看两遍。数据在自己硬盘上，和「免费」是两件事，别混着高兴。
- 一个功能要用自己的 key 才能开，那它在说明书里就该写在第一行。我翻到后面才看见。

最后我把内网那几条单独存成一份文本，没进这个软件。有些东西不该和别的书签待在一起。
